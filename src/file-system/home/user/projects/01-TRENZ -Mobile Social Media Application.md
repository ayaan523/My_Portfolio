# TRENZ | Mobile Social Media Application
## 2026

Tech Stack: Flutter, Dart, Supabase, PostgreSQL, Provider, CustomPainter

Built a high-performance Flutter application from scratch, utilizing the Impeller rendering engine to deliver a fluid, 60fps cross-platform experience for iOS and Android.

Managed complex application state using Provider, building a highly decoupled architecture that supports per-chat visual overrides, custom gallery media ingestion, and dynamic font switching.

Optimized client-side UI rendering by replacing heavy widget trees with low-level CustomPainter canvas draw calls, efficiently rendering complex geometric backgrounds and matrix UI patterns.

Programmed an on-device PDF generator that translates RESTful AI-JSON responses into highly formatted, monochromatic Harvard-style resumes.

Handled asynchronous data streams using StreamBuilder and Supabase Realtime to update UI states instantly for typing indicators, read receipts, and live job boards.
