# Angle-3D — 3D Angle Visualization Tool
## 2025

Tech Stack: React, TypeScript, Three.js, Tailwind CSS

Developed an interactive 3D visualization tool using Three.js for dynamic angle measurement.

Implemented real-time rendering of 3D geometries with precise angle calculations.

Built responsive UI using React and Tailwind CSS for intuitive interaction.

Designed modular and scalable component architecture for geometry management.

Integrated mathematical logic for accurate spatial visualization.
