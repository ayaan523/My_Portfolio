# SHADOW | AI-Powered LMS
## 2026–Present

Tech Stack: Node.js, Express.js, TypeScript, PostgreSQL, Prisma ORM, Zod, JWT, bcrypt, Redis, REST

A full-stack AI-powered Learning Management System with scalable REST APIs. Implemented secure authentication and authorization with JWT, bcrypt, Refresh Tokens, RBAC, Zod validation, and centralized error handling following industry best practices.

Built a modular backend using the Controller–Service–Repository architecture, ensuring maintainability, scalability, and clean code principles.

Engineered features including course management, AI tutoring, assessments, student progress tracking, analytics, and real-time communication.
