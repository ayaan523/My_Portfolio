# LandLens — AI Land Evaluation & Visualization
## 2025–2026

Tech Stack: React, TypeScript, Three.js, Google Maps API, Places API, Chart.js, Tailwind CSS

Built an interactive 3D land visualization interface using React and Three.js, allowing users to dynamically inspect spatial land data.

Implemented an image upload feature that parses EXIF metadata to automatically extract GPS coordinates for precise location detection.

Integrated Google Maps and Places APIs to query nearby amenities, feeding geographical data into the valuation logic to estimate property values.

Developed a responsive analytics dashboard using Chart.js to render real-time data visualizations for land valuation trends and predictions.

Designed a modular frontend architecture in TypeScript, ensuring strict type safety and scalable state management.
